Getting started
===============

Supported Python versions
-------------------------

* Python 3.9
* Python 3.10
* Python 3.11
* Python 3.12
* Python 3.13
* Python 3.14

Supported Django versions
-------------------------

* Django 3.2
* Django 4.0
* Django 4.1
* Django 4.2
* Django 5.0
* Django 5.1
* Django 5.2
* Django 6.0
* Django 6.1

Installation
------------

.. code-block:: bash

    $ pip install -U django-templated-mail

No need to add it to your ``INSTALLED_APPS``.
